# Mục lục sổ kiến thức

Đọc file này đầu tiên. Mỗi file có `cap_nhat` và `can_kiem_tra_lai_sau_ngay`; `python tools/kb.py cu` cho biết file nào cần nghiên cứu lại.

| File | Nội dung | Ai cập nhật |
|---|---|---|
| `learnings/LEARNINGS.md` | Mọi bài học, có bằng chứng | mọi agent |
| `experiments/EXPERIMENTS.md` | Thí nghiệm đang chạy và kết quả | growth-advisor, sales-optimizer |
| `rules/compliance.md` | Quy định Gumroad, mã nguồn mở, cách nói về bảo mật, luật cộng đồng | compliance-checker |
| `products/vutty.md`, `products/vutidy.md` | Sự thật về sản phẩm, điểm mạnh, điểm yếu | market-researcher (sau mỗi bản phát hành) |
| `market/competitors.md` | Đối thủ và giá | market-researcher |
| `market/channels.csv` | Kênh quảng bá để chấm điểm | growth-advisor, content-marketer |
| `market/trends-log.md` | Nhật ký thị trường hằng tuần | market-researcher |
| `brand/brand-book.md` | Định vị, giọng nói, hình ảnh | brand-strategist |
| `playbooks/gumroad-page.md` | Trang bán, giá, sau khi bán | sales-optimizer |
| `playbooks/content.md` | Kiểu bài, quy tắc viết | content-marketer |
| `performance/*.csv` | Số liệu Gumroad và GitHub theo tuần | người dùng, growth-advisor |
| `directions/YYYY-MM.md` | Định hướng mỗi tháng | growth-advisor |
| `sources.md` | Nguồn và độ tin | market-researcher |
